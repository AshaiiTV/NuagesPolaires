**Ce qui est solide — cinq points**

- PBKDF2 compatible avec l’ancien code : SHA‑256 hex intermédiaire, sel transmis comme chaîne, comparaisons `timingSafeEqual`, rehash atomique et paramètres bornés.
- Jetons aléatoires de 32 octets, empreintes HMAC, cookies correctement configurés ; finalisation du reset et révocation regroupées en transaction.
- Origine contrôlée avant ouverture de base ; `NP_SITE_URL` absent refuse le démarrage en production. L’API inspectée expose uniquement une lecture GET protégée.
- CSP Kit configurée avec nonces SSR et restrictions objet/base/cadrage ; identifiants et couleurs injectés par le thème sont filtrés. L’adapter Netlify lit `context.ip`, sans lecture applicative de `X-Forwarded-For`.
- Pool fermé dans `finally` ; vues de comptes filtrées sans hashes ; jetons OAuth non persistés ; verrou commun ordonné pour protéger le dernier administrateur.

**Les huit tests à ajouter en priorité**

1. Amorçage d’un pseudo précréé avec Discord hostile : après reset, cette identité doit être refusée ; couvrir également la récupération d’un admin compromis.
2. Requête suspendue après le hook, puis logout/reset/déliaison/déclassement : participation, consommation et mutation staff doivent échouer sans écriture.
3. Session expirant entre hook et transaction : tester une mutation de compte et une mutation administrative.
4. Dix échecs visant une victime : vérifier le parcours légitime depuis une autre IP et l’accès à la récupération admin.
5. Matrice normative exhaustive : MJ refusé pour validation/rejet d’observation, designer et admin autorisés.
6. Échecs sur compte inconnu, SHA‑256, hex, PBKDF2, scrypt et hash malformé : vérifier le chemin de coût commun, puis comparer les distributions temporelles.
7. Retours de connexion contenant tabulations, contrôles, antislashs et URL externes : aucune destination finale hors origine.
8. Sur Postgres avec deux connexions : récupération simultanée sans admin, avec/sans compte préexistant ; une seule consommation effective. Inclure les retraits concurrents des derniers admins.
