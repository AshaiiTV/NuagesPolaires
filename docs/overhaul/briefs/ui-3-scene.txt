À CONSTRUIRE
1. /carnet/scene (régime scene ; <Enveloppe regime="scene">) — le feuillet volant, pensé pour un téléphone tenu d'une main (390 px d'abord ; sur ordinateur : colonne de 420 px). Bande de contexte « SCÈNE · #salon · 21:42 » + LigneEtat ; si une Table implique le personnage : « Round 3 · déclarations » ou « Le MJ résout. » avec lien vers /carnet/table/[id].
   - Ressources : PV, EP, EM sur trois lignes, chiffre 24 px tabulaire, maximum en encre-2 ; statuts (Losange) ; sous chaque ressource les déclarations de la scène en encre du joueur.
   - Déclarer : un lien texte par ressource ouvre UNE LIGNE DE CARNET (pas une barre de touches) : « <Nom> déclare … » suivi d'un choix de mots avec leur coût imprimé (ACTION_RULES de rules.ts pour l'EP ; capacités de la branche au niveau atteint pour l'EM ; « subis … PV », « soigné de … PV », « autre… » avec chiffre et mot obligatoires). Affiche les libellés SANS émoji (retire les pictogrammes des libellés hérités). Après envoi (action ?/declarer) : « Kael déclare −8 EP (Esquive). » humide puis prise, « Annuler · 10 s » (compte à rebours visible, action ?/annuler), ensuite seulement « Rayer ». Le chiffre du relevé ne change jamais.
   - Capacités à ton niveau : paliers atteints de la branche (nom, coût, texte complet), le suivant en encre grise ; sans branche : phrase exacte de §5.3.
   - Objets : liste plate, « Consommer » → confirmation en une ligne (action ?/consommer).
   - Bloc à coller : aperçu monospace de trois lignes exactement comme en §5.3 ; « Copier pour Discord » (navigator.clipboard) devient « Copié · 21:44 — colle-le dans le salon. » 4 s.
   - Note rapide : une ligne « Noter pour le journal » (action ?/noter, inScene).
   - Barre basse ancrée : « Règle » (ouvre UNE carte choisie par ruleCardFor selon le contexte, avec « Voir dans le système de jeu → »), « Copier pour Discord », « Reposer » (propose la ligne « Où j'en suis » + « Lien du message Discord » : action ?/marquePage, puis retour à la page précédente ou /carnet).
   - Sans scène ouverte : proposer d'en ouvrir une (titre + lien du salon, action ?/ouvrirScene) ; le feuillet reste utile sans scène.
   - États : pas de réseau (« Pas de réseau. Tes chiffres restent ceux de 21:14. », déclaration humide + « Réessayer »), compte non lié (redirection /carnet), Table repliée.
2. /carnet/table/[id] (régime scene) — exactement §5.9 : en-tête « À la table — <nom> · Round N · <phase> », « Dernier état reçu à hh:mm » ; mon personnage (trois ressources 24 px telles que le MJ les tient, statuts, « Le MJ attend ta déclaration sur Discord. » ou « Le MJ résout. ») ; alliés puis adversaires en lignes compactes (adversaires : état narratif LÉGER / GRAVE / CRITIQUE à la place des chiffres sauf si la projection fournit les chiffres) ; sous un filet les lignes de récit des rounds, la plus récente en bas ; à chaque changement reçu, l'ancienne valeur reste en Rature 4 s (« 24 → 18 » : <Rature ancien=24 nouveau=18>) et « Round 3 · résolu à hh:mm » s'écrit. Mise à jour : sondage de /api/table/[id]/etat toutes les 4 s avec If-None-Match, arrêté quand l'onglet n'est pas visible (document.visibilityState), repris au retour ; retard > 8 s : « Dernier état reçu à hh:mm · en retard de N s. » ; échec : « Plus de nouvelles de la Table depuis hh:mm. » + « Réessayer » ; Table repliée : phrase exacte ; non participant : 404 avec « Cette Table n'est pas la tienne. ». AUCUN élément cliquable dans la zone de la Table ; seuls « Copier pour Discord », « Règle », « Ouvrir le salon ↗ » en bas.
