À CONSTRUIRE (régime serre ; src/routes/registre/+layout : requireCapability 'admin.accounts' ; sous-navigation : Ce qui attend · Comptes et liaisons · Thèmes · Journal d'audit · Données)
1. /registre — « Ce qui attend » : « Liaisons » en deux colonnes (comptes en attente à gauche avec date d'inscription ; personnages sans compte à droite ; on sélectionne un compte puis un personnage — radios — puis « Lier » : trois gestes, action ?/lier, tampon d'administrateur affiché après la réponse) ; réinitialisations de mot de passe non achevées avec leur échéance ; anomalies de migration s'il y en a (migrationStatus). Vide : « Rien n'attend. Le registre est à jour. ».
2. /registre/comptes : une ligne par compte (pseudo, rôle en capitales espacées, « relié à … » ou « en attente de liaison », dernière venue datée) ; recherche et filtre par rôle (paramètres d'URL) ; actions en ligne : lier / délier (?/lier, ?/delier), changer le rôle (?/role ; le dernier administrateur est protégé : message du serveur), « Réinitialiser le mot de passe » (?/reinitialiser → le code temporaire s'affiche UNE SEULE FOIS dans une note de marge avec son échéance « valable une heure » et la consigne « À transmettre au propriétaire du compte. Il devra choisir un nouveau mot de passe à la connexion. » ; jamais stocké côté navigateur), « Rayer ce compte » (saisie du pseudo ; ?/rayer). Téléphone : consultable ; opérations sensibles « Sur ordinateur ».
3. /registre/themes : galerie de feuillets (aperçu des huit tokens comme une petite page), pour chaque thème : visible ou non, distribué à tous ou non ; « Donner à un compte » (choix du compte), « Donner à tous », « Retirer », visibilité ; « Nouveau thème » : identifiant, nom, description, huit couleurs (inputs color + hex) avec aperçu vivant et contrôle de contraste affiché (ratio encre/page et encre-2/page ; sous 4,5:1 le bouton d'enregistrement n'est pas proposé et la raison est écrite).
4. /registre/journal : page à réglure visible, une ligne par action (date et heure en marge, source, acteur, action, détail lisible), filtres acteur · action · dates (paramètres d'URL), 50 par page, jamais éditable ; « Exporter (.txt) » (?format=txt) ; onglet « Journal du staff » (listStaffLog) présenté de la même façon.
5. /registre/donnees : export JSON (action ?/exporter → téléchargement ; mention exacte « Ce n'est pas une sauvegarde complète du site. »), état de la migration (« 12 fiches reprises sans rature », anomalies), diagnostics sûrs (base joignable, variables d'environnement présentes ou absentes — jamais leur valeur —, version), réglages : lien d'invitation Discord du pied de page (action ?/reglage ; URL https://discord.gg/… ou https://discord.com/invite/… uniquement).
Captures exigées (--compte=admin) : les cinq pages à 1440 et 390 ; la création d'un thème avec un contraste insuffisant (refus visible) ; --compte=mj sur /registre doit donner une 404.
